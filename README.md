# Carrot REST Web

Веб-клиент для Carrot Broadcast: плейлисты, события, Excel-импорт, медиа.

Всё нужное — в [`carrot/rest-client`](carrot/rest-client):

```bat
cd carrot\rest-client
copy .env.example .env
web.cmd
```

Открыть [http://127.0.0.1:3456](http://127.0.0.1:3456). Подробности — в
[`carrot/rest-client/README.md`](carrot/rest-client/README.md).
