# Carrot Flask Web

Веб-клиент Carrot Broadcast (Flask + HTML/CSS/JS).

```bat
cd carrot\flask-client
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
web.cmd
```

Открыть http://127.0.0.1:3456. Подробности —
[`carrot/flask-client/README.md`](carrot/flask-client/README.md).
