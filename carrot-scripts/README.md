# Сценарии для Carrot Broadcast

Подборка готовых скриптов для программы **Carrot Broadcast** (реалтайм-графика, виртуальные студии, AR).
Сценарии пишутся на **JavaScript (ES3)** и запускаются в **Script Editor** приложения **Template Preview**
(меню `Edit → Scripts`, либо горячая клавиша `Ctrl + N`).

Подробная официальная документация:

- Руководство по сценариям: <https://carrotsoftware.github.io/scripting/>
- Справочник объектов/методов: <https://carrotsoftware.github.io/scripting/#/reference-guide>
- Жизненный цикл шаблона: <https://carrotsoftware.github.io/scripting/#/life-cycle>

## Жизненный цикл шаблона

Шаблон проходит стадии: **Load → Take In (In) → Take Out (Out) → Unload**.
В режиме **Process Frame** скрипт вызывается каждый кадр (обычно 25–60 раз в секунду),
поэтому в нём старайтесь избегать циклов `for` / `while` и тяжёлых вычислений.

## Переменные

| Вид | Синтаксис | Область видимости |
| --- | --- | --- |
| Обычная | `var a = 10;` | Один шаблон |
| Локальная | `local.a = 10;` | Одна схема Carrot Engine |
| Глобальная | `global.a = 10;` | Все схемы одного Carrot Server |

## Содержимое папки

| Файл | Что делает |
| --- | --- |
| `01-hello-world.js` | Простейший вывод в панель **Info** и всплывающее окно. |
| `02-project-info.js` | Печатает список элементов шаблона, их тип и ID. |
| `03-change-text.js` | Меняет текст текстового слоя через `setValue()`. |
| `04-transform-layer.js` | Двигает, масштабирует и вращает слой. |
| `05-random-position.js` | Ставит слой в случайную позицию (с `generateRandomNumber()`). |
| `06-effect-parameter.js` | Получает и меняет параметр эффекта. |
| `07-process-frame.js` | Пример для режима **Process Frame** (без циклов). |
| `08-global-variables.js` | Демонстрация `var`, `local.*` и `global.*`. |
| `09-footage-info.js` | Работа с медиа (`footage()`), вывод размеров и длительности. |
| `10-safe-access.js` | Безопасный доступ к композициям/слоям с проверкой на `null`. |
| `11-lower-third-autofit.js` | Нижняя плашка: парсинг текста на строки, автоуменьшение шрифта/трекинга, сдвиг Null-слоя по числу строк (без анимации opacity). |

Все скрипты можно скопировать в **Script Editor** и запустить как есть —
при условии, что в шаблоне есть упомянутые имена композиций/слоёв
(иначе замените имена на ваши).
