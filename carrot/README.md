# Comments Loop — Carrot Broadcast

Скрипт для композиции, где два текстовых слоя **Comment 1** и **Comment 2**
по очереди появляются/исчезают, а строки для них берутся из слоя **MainText**.

Файл [`comments-loop.js`](./comments-loop.js) разбит на три блока-заготовки.
Скопируй каждый блок в соответствующее поле Carrot:

| Поле Carrot   | Блок в файле                        |
| ------------- | ----------------------------------- |
| **Startup**   | всё от `// STARTUP` до `// SETSTATE` (var'ы + функции) |
| **SetState**  | блок `if (statename == "LOOP") { initLoop(); }` |
| **ProcessFrame** | блок `if (statename != "LOOP") ... else if (...)` |

## Как это работает (без рассинхрона)

Текст плашки меняется **ровно в тот кадр, когда плашка стала скрытой** —
скрипт следит за её прозрачностью (`transform.opacity`). Смена привязана
к самой анимации композиции, поэтому:

- **нет накопительного дрейфа** — не важно, сколько минут идёт цикл;
- смена происходит, когда плашка уже невидима → нет мигания;
- точные тайминги (0.18 / 5.96 / 0.2) скрипту знать **не нужно**.

Порог «скрытости» задаётся в `Startup`:

```js
var HIDE_LEVEL = 1;   // прозрачность (%), ниже которой плашка считается скрытой
```

## Логика подстановки строк

- Comment 1 показывает строки `0, 2, 4, ...`, Comment 2 — `1, 3, 5, ...`.
- На экране строки идут последовательно `0, 1, 2, 3, ...` и зацикливаются.

Особые случаи:
- **пустой MainText** — оба слоя скрываются (`Enabled = false`);
- **одна строка** — обе плашки показывают её же;
- **зацикливание композиции** (`time` сбросился) — цикл переинициализируется
  (снова строки 0 и 1).

## Если скрытие сделано НЕ через прозрачность

Скрипт определяет видимость через `transform.opacity`. Если в твоей
композиции плашка прячется иначе (сдвиг позиции, масштаб, маска и т.п.),
поправь тело функции `isVisible()` под нужную проверку, например:

```js
function isVisible(name)
{
    // пример: плашка «уехала» за левый край экрана
    return thisComp.layer(name).transform.position[0] > -100;
}
```
