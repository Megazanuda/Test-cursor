# Comments Loop — Carrot Broadcast

Скрипт для композиции, где два текстовых слоя **Comment 1** и **Comment 2**
по очереди появляются/исчезают, а строки для них берутся из слоя **MainText**.

Файл [`comments-loop.js`](./comments-loop.js) разбит на три блока-заготовки.
Скопируй каждый блок в соответствующее поле Carrot:

| Поле Carrot   | Блок в файле                        |
| ------------- | ----------------------------------- |
| **Startup**   | всё от `// STARTUP` до `// SETSTATE` (var'ы + функции) |
| **SetState**  | блок `if (statename == "LOOP") { initLoop(); }` |
| **ProcessFrame** | блок `if (statename != "LOOP") ... else if (...)` |

## Тайминги

Заданы вверху `Startup`:

```js
var START_TIME   = 0.18;   // появление первого комментария
var DISPLAY_TIME = 5.96;   // сколько висит на экране каждый комментарий
var GAP          = 0.2;    // пауза между исчезновением одного и появлением другого
var PERIOD       = DISPLAY_TIME + GAP;  // 6.16 — период чередования
var PRELOAD_TIME = GAP;    // за сколько до появления менять текст (пока слой скрыт)
```

Раскладка по времени (при 2+ строках):

```
Comment 1 (строка 0):  0.18 .. 6.14
Comment 2 (строка 1):  6.34 .. 12.30
Comment 1 (строка 2): 12.50 .. 18.46
Comment 2 (строка 3): 18.66 .. 24.62
...
```

Смена текста скрытого слоя происходит в момент паузы `GAP` (например, текст
для Comment 1 со строкой 2 ставится в 12.30 — ровно когда исчезает Comment 2,
а сам Comment 1 появится только в 12.50). Поэтому смена текста не видна.

## Логика подстановки строк

Каждое появление — это «слот» с номером `0, 1, 2, ...`:

- чётный слот → **Comment 1**, нечётный → **Comment 2**;
- содержимое слота `k` = `arrLocation[k % N]`, где `N` — число непустых строк.

В итоге на экране строки идут последовательно `0, 1, 2, 3, ...` и зацикливаются,
а физически чередуются между двумя слоями.

Особые случаи:
- **пустой MainText** — оба слоя скрываются (`Enabled = false`);
- **одна строка** — обе плашки показывают её же;
- **зацикливание композиции** (`time` сбросился) — цикл переинициализируется.

## Что было исправлено относительно исходного скрипта

- `COMMENT_PERIOD` теперь считается из реальных таймингов: `5.96 + 0.2 = 6.16`
  (в исходнике было жёстко `6.0`, что рассинхронизировалось с анимацией).
- Comment 1 и Comment 2 трактуются как два **независимых** чередующихся слоя,
  а не «дисплей + буфер» (раньше текст Comment 2 копировался в Comment 1).
- Текст меняется строго пока слой **скрыт** (в паузе `GAP`), без мигания.
- Индексация строк вынесена в единую формулу `slot % N` — не теряются и не
  дублируются строки при любом их количестве.
- Общая (пере)инициализация вынесена в `initLoop()` и переиспользуется
  в `SetState` и при зацикливании.
- Автоподгон масштаба (`autoScale`) оставлен готовой опцией — включается
  раскомментированием одной строки в `setComment`.
